# Margo Program (PWA)

Margo's glute-priority training app: 3 core sessions + optional 4th, workout logging with progression tips, rest timer, history, and her Food tab (Morning snack, Meals 1–3, dinner rotation, her targets, gap-closer, supplements, food rules). Plain HTML/CSS/JS, GitHub Pages, works offline.

- `data.js`: program (exercises, sets × reps, rest, swaps, tempo, cues)
- `food-plan.js`: Margo's portions and targets from the shared couple meal library; `food-log.js`: day log + gap suggester
- Images: free-exercise-db (public domain)

On iPhone: Safari → Share → Add to Home Screen.
